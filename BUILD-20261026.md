- Personal blocker → practical strategy → next action → check-in/lesson. Reusable strategies, in-app routine tasks and pattern summaries based on recorded attempts, with missing feedback and small samples treated honestly.
- Additive Demo setup: 823 connected sample records across 20 entity types, including 90 days of history and sample documents. Demo is separate from Personal and disabled automation examples do not run.
- Visible press/save/error feedback, readable overdue rows, safer hiding/removal, configurable progress controls, editable subtasks and explicit Tool Router task saving.

## Explicit remaining deployment work

Preferences and Focus recovery/history currently live on this device/account; export backup includes them. Base44 owns the other saved records. The client serializes relevant writes and guards capacity/ownership, but this does not provide server transactions, complete offline sync or cross-device conflict safety. Finish/conversion recovery in this preview spans multiple Base44 calls.

backend/supabase/migrations/ contains the core PostgreSQL model, ownership/RLS, transactional idempotent commands, serialized capacity, optimistic versions, hierarchy/finish rules, recurrence registry, sync changes/tombstones and recovery commands. It has not been deployed. Supabase auth, a data migration, private storage policies and production account deletion still need real project configuration. Do not assume Base44 authentication or IDs transfer automatically.

android-migration/ contains Room/outbox/WorkManager migration source and integration instructions. It is not compiled or wired into this Capacitor APK. The Android binary retains App and Browser plugins. Phone notifications are unavailable and the UI says so; reminders currently appear in-app. Account deletion is disabled pending a real server endpoint. Brief delivery/quiet-hour preferences are saved but do not schedule Android alerts.

## Recovery and rebuild

The source ZIP includes package-lock.json, Base44 entity/function source, Android project, migrations, sample documents and verification results. Signing keys, private environment files, dependency/build caches and generated frontend Android assets are excluded. Keep the original keystore separately; using another certificate can prevent an in-place update.

Install dependencies with npm ci, run npm run lint and npm run build, then npx cap sync android. A normal Android rebuild requires a configured JDK/SDK/Gradle environment. This delivered APK preserves the prior native shell/DEX and packages the tested frontend using apktool 2.12.1 and Android build-tools 35, followed by zipalign and the original signer. No new native plugin is compiled into that shell.
